How does a machine learn?

You show it plenty of examples; seeing the right answer again and again, it works out the pattern itself. You never write the rules.

It studies labeled examples: an input x paired with its correct answer y. A loss function measures how wrong each guess is; gradient descent shrinks that loss step by step until it has learned the mapping f(x; θ) from x to y.
